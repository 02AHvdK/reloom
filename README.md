# RELOOM

让长期使用的 Agent 指令重新变得可读、可检查、可编辑。

Agent 用久了，局部调整会不断累积；隔一段时间再打开，也很难记清里面到底写了什么。RELOOM 把指令文件转成文档与节点结构，帮助你定位细节、自己修整，并检查修改后再导回原文件。

## 开始使用

需要 Node.js 22.12 或更新版本。

```sh
npm ci
npm run build
npm start
```

打开 http://127.0.0.1:4317 。开发模式使用 `npm run dev`。Windows 可使用 `start.cmd`。服务仅监听本机。

[下载发布包](https://github.com/02AHvdK/reloom/releases) · [建议反馈](https://github.com/02AHvdK/reloom/issues/new?template=feedback.yml)

## 功能

- 导入 Markdown、JSON、YAML，以及受支持的 n8n / Dify 文件。
- 文档总览、章节导航、节点工作流、源文件与修改检阅共享同一份内容。
- 编辑标题与正文、添加子节点、调整节点类别；内部类别标记由选择器管理。
- 横向 / 纵向布局、全屏画布、节点对齐、撤销与重做。
- 本地库、快照备份、格式导出和导回；可配置兼容模型接口辅助检查。
- 明暗主题、快捷键设置、可关闭的开场动画。
- **更新与反馈**：侧栏和底部状态栏均有入口。手动读取 GitHub Releases，对比语义版本；失败不会误报“最新”。反馈打开 GitHub 表单，由你确认后提交。

## 数据与能力边界

文档存放在当前浏览器的本地存储中，迁移前请导出备份。模型密钥仅保留在页面内存。更新检查只向 GitHub 查询公开版本，不上传文档；反馈也不会自动附带文档或密钥。

Markdown 的树形结构表达章节关系，不代表任意自然语言已经可以自动执行。软件调用限于本机检测到的预设应用；保存调用规则不会自动运行软件。模型功能需要自行配置接口。

## 字体

公开版本包含 Jost 与思源黑体，许可证位于 `public/fonts/`。设备已安装 Futura 时可使用本地字体；仓库及公开发布包不分发 Futura 文件。

## 验证与发布

```sh
npm test
npm run build
```

当前版本见 `package.json`。发布标签使用 `v主版本.次版本.修订号`；正式版本检查忽略草稿和预发布版本。测试版会包含预发布版本。更新仅提示并提供下载链接，不会静默替换本机程序。

本仓库未为项目原创代码授予额外开源许可。第三方组件与字体遵循各自许可证。
